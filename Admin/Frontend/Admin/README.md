# ISeeYou Admin Frontend

ISeeYou 관리자 화면은 사용자 분석 기록, 모델 판정 결과, 사용자 이벤트, 관리자 검수 결과를 확인하는 React 기반 운영 콘솔입니다.

## 주요 화면

- 로그인 화면
- 운영 대시보드
  - 분석 처리 요약
  - Real/Fake 비율
  - 최근 7일 분석량
  - 사용자 이벤트 흐름
  - 관리자 검수 요약
- 분석 기록 테이블
- 분석 상세 패널
  - 입력 미리보기
  - 모델 점수
  - 관리자 검수
  - 처리 타임라인

## 실행

```powershell
cd Admin\Frontend\Admin
npm install
npm run dev
```

기본 개발 서버:

```text
http://127.0.0.1:5175
```

## 빌드

```powershell
npm run build
```

## API 연결

관리자 프론트엔드는 같은 origin의 `/api/admin/*` 경로를 호출합니다. 개발 서버에서는 `vite.config.ts`의 proxy가 관리자 백엔드로 요청을 전달합니다.

기본 백엔드:

```text
http://127.0.0.1:8787
```

## 검수 기능

관리자는 각 분석 기록 상세 패널에서 모델 판정과 실제 검수 판정을 비교할 수 있습니다.

- 모델 판정과 관리자 판정 일치: `일치`
- 모델 Fake, 관리자 Real: `오탐`
- 모델 Real, 관리자 Fake: `미탐`
- 관리자 판정 미선택: `판단 보류`

검수 결과는 관리자 대시보드의 정답률, 오류 수, 오탐/미탐 수, 재학습 후보 수에 반영됩니다.
